## Interpretation boundaries

Level 2 permits NL-to-Cypher; a LangGraph multi-step agent is not claimed. This implementation produces a constrained query plan and compiles actual Cypher; the compiler's behavior is inspectable. General GDS/ML rubric items are included despite the project being Level 2. The owner's private-visibility preference is preserved rather than silently publishing embedded source code.
